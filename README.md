# Homey snippets

My collection of smart home code for Homey. HTML dashboard snippets are single, self-contained files. HomeyScripts will be plain JavaScript files.

## Dashboard snippets

- [Rotating image gallery](dashboard/rotating-gallery.html)
- [How to use it in Homey Dashboards and HDashboards](dashboard/README.md)
- [Open the live gallery](https://binarybrigadecom.github.io/homey-snippets/dashboard/rotating-gallery.html)

The gallery currently uses sample images from `picsum.photos`. Replace them with your own image URLs in the `CONFIG` section at the top of the HTML file.

This repository and its GitHub Pages site are public. Keep Homey credentials, tokens, and private image links out of the files.
